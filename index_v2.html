About EIMS

The Engineering Inventory Management System (EIMS) tracks registered tools borrowing and returns across the workshop's cabinets in real time using RFID cards and tags at a physical station plus web dashboard for traceability and monitoring.

How to Use EIMS

1. Connecting to the System

  • Connect your device (phone, tablet, or PC) to the system's local Wi-Fi network: SSID: EIMS - ESP32 / Password: 12345678.
  • Open a web browser and navigate to the IP address provided by the system on startup.

2. User Mode (Borrowing & Returning)

  • Ensure the physical hardware switch on the unit is flipped to User Mode.
  • Start Session: Tap your registered Engineer ID card on the RFID scanner. The system will greet you.
  • Borrow/Return: While your session is active, tap an available tool tag to borrow it. Tap a borrowed tool again to return it.
  • Transfer: If another engineer needs a tool you have, they can simply tap their ID card to take over the session, then tap the tool to transfer it to their name.
  • End Session: Tap your Engineer ID card again to log out, or allow the system to auto-timeout after 10 seconds of inactivity.

3. Admin Mode (Registration & Management)

  • Flip the physical hardware switch to Admin Mode.
  • Navigate to the Add/Delete tab on the web dashboard and log in (Default Username: admin / Password: 123).
  • Registering Tools/Engineers: Type the desired ID and Name into the respective fields and click "Add". The system will enter a standby state. Physically tap a blank RFID tag or card on the scanner to burn the ID and finalize registration.
  • Bulk Management: Use the "Menu" button on the dashboard to select multiple tools at once to move them between cabinets, change their layers, mark them inactive, or delete them.
  • History Export: Go to the History tab to download CSV reports organized by individual items or user sessions.

System Specifications

  • Hardware Setup: Powered by an ESP32 microcontroller, utilizing an MFRC522 RFID Scanner for tool and engineer tags, a NeoPixel LED and Buzzer for physical feedback, and a hardware toggle switch for Admin/User mode selection.
  • Network & Storage: Operates as a standalone Wi-Fi Access Point. Data is stored locally in JSON format with automatic fail-safe backups (.bak files) and memory-efficient write cycles.
  • Inventory Management: Features multi-cabinet support, dynamic UI carousels, live tool search, and bulk operations (move, set layer, deactivate, delete, and force return).
  • User/Engineer Management: Register engineers securely via RFID cards, track session login/logout durations, and manage active/inactive statuses.
  • Real-Time Dashboard: A responsive web interface with live sync, toast notifications, dark/light theme toggles, and real-time state tracking (Available, Borrowed, Transferred).
  • Reporting & Logs: Comprehensive transaction and session history logging with automatic weekly database rollovers and CSV export capabilities.
